# Assets

Icons, images, and other binary resources.

## Files (planned)

| File | Purpose | Format | Notes |
|---|---|---|---|
| `icon.ico` | System tray icon | Windows .ico, 16 + 32 + 48px | Shown in the taskbar tray |
| `icon-32.png` | Popup accent dot / logo | PNG, 32x32 transparent | Used inside the WPF popup header |
| `favicon.png` | Web-facing icon (docs, README) | PNG, 512x512 | For future GitHub / site references |

## Design intent

Warm sunrise gradient — `#F5A87A -> #E85F62` — on a subtle geometric mark (curved arrow implying "grab / pull"). Kept minimal to survive the small sizes of taskbar / favicon.
